# V0.2 — Demo Direzione / Commerciale / PM

## Obiettivo
Trasformare la prima V0 tecnica in una demo orientata alla decisione, mantenendo invariata l'architettura API-first e il Rules Engine.

## Aggiunte principali
- esposizione economica di portafoglio;
- priorità comprensibile (criticità critica / alta / da presidiare / sotto controllo) con Attention Score secondario;
- KPI semanticamente colorati;
- filtri portfolio per commerciale, PM, stato e priorità;
- Executive Health per singola commessa;
- azioni suggerite per ogni alert e creazione di action dal cockpit;
- Project Closing con blocchi tecnici, documentali, economici e contrattuali;
- timeline unica di commessa;
- ripristino dati demo;
- visibilità per ruolo già attiva.

## Non incluso in V0.2
- collegamento reale a Galileo, Pipedrive, Outlook/Graph o file server;
- LLM reale: le comunicazioni usano ancora AGENT_SIM;
- stima contrattuale definitiva delle LD: il cockpit segnala il rischio ma non espone un valore economico senza cap/condizioni validate;
- autenticazione Entra ID reale.

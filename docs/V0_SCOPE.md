# V0 Scope congelato

## Utenti
- Direzione: portfolio completo.
- Commerciale: solo proprie commesse.
- PM: solo proprie commesse.

## Scenari demo
1. Commessa chiusa tecnicamente con insoluto.
2. Milestone Delivery raggiunta ma non fatturata.
3. Richiesta cliente senza risposta / solleciti.
4. Forecast budget oltre baseline.
5. Ritardo contrattuale con LD.
6. Extra richiesto e lavorato senza ordine cliente.
7. Documentazione bloccante acceptance/fatturazione.
8. Criticità tecnica prima del SAT.
9. Action scaduta.
10. Commessa sana.
11. Ritardo moderato senza LD.
12. Nuova commessa in handover.

## Alert workflow
OPEN -> ACKNOWLEDGED -> RESOLVED / IGNORED.

## Import
Workbook standard con PROJECTS, MILESTONES, BUDGET, COSTS, INVOICES, PAYMENTS, ACTIONS.
